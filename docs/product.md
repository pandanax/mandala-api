# Продукт

## Назначение

Агент помогает пользователю пройти сценарий «своя личная мандала»: собирает необходимые данные (имя, дата/время/место рождения и др.), опирается на заданную методику (нумерология, сакральная геометрия, подготовленные тексты в базе знаний), объясняет, как интерпретировать и при желании **как рисовать** мандалу.

В платной версии возможна **генерация изображений** (отдельная модель/API); в бесплатной — ограниченное число текстовых ответов и настраиваемое число картинок (в т.ч. ноль).

## Каналы

- **Сейчас (план):** Telegram.
- **Дальше:** Web, CLI, другие мессенджеры — без переписывания домена и агента, только новые адаптеры и точки входа.

## Монетизация

- Модель — **предоплаченный кошелёк сообщений**, БЕЗ подписки и месячных лимитов (см.
  [billing.md](billing.md), [quotas-and-plans.md](quotas-and-plans.md)).
- Новый пользователь получает **разовый стартовый грант** (по умолчанию 20 сообщений);
  каждый **LLM-ответ текстом списывает 1**, мгновенные детерминированные рендеры
  (`/natal`, `/matrix`, `/numerology`, `/profile`, `/help`) не списывают.
- Пополнение — **три пакета Telegram Stars** (1⭐→100 / 2⭐→300 / 5⭐→1000); купленные
  сообщения **не сгорают**, зачисление идемпотентно. Кнопка/команда — **«Купить сообщения»**
  (`/topup`), в шапке показывается текущий баланс.
- **Промо-код = вечный безлимит**; баланс и промо **переживают `/reset`**.
- Архитектура допускает **Stripe**, **ЮKassa** и др. без смены бизнес-логики.

## Юридический и продуктовый контекст

Контент позиционируется как развлекательный/эзотерический; ответственность за формулировки и дисклеймеры — на стороне продукта (отдельно от этого технического ТЗ).

## Успех MVP

- Пользователь может пройти сценарий в Telegram до осмысленного результата (натальная карта /
  Карта судьбы / нумерология + навигация по темам).
- Списание из кошелька сообщений атомарно, без ухода в минус и без гонок.
- Платёж Stars идемпотентно зачисляет сообщения на баланс.
- Профиль, баланс и промо не теряются между сессиями (и переживают `/reset`).
