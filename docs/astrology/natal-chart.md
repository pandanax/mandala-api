# Натальная карта: что считается и как

> Математика натальной карты в контексте Mandala.
> Код: `src/mandala/astro/natal_chart.py`.

## Что такое натальная карта

Натальная карта (horoscope natalis, birth chart) — «снимок» неба в момент рождения.
Астрологически определяет:
- В каком знаке зодиака находится каждая планета (Solar sign, Moon sign, и т.д.)
- В каком доме (house) каждая планета
- Асцендент (Ascendant / Rising sign) — знак, восходящий на горизонте в момент рождения
- Угловые отношения между планетами (аспекты)

Три ключевых данных для расчёта:
1. **Дата рождения** — определяет позиции Солнца, медленных планет
2. **Время рождения** — критично для Луны, Асцендента и домов (Луна движется ~1° в час)
3. **Место рождения** — географические координаты для расчёта домов и местного звёздного времени

## Как считает код Mandala

### Стек

| Компонент | Назначение |
|-----------|-----------|
| `httpx` + Nominatim (OpenStreetMap) | Геокодинг города → (lat, lng) |
| `timezonefinder` | (lat, lng) → часовой пояс |
| `kerykeion` | Обёртка над Swiss Ephemeris (Python) |
| `pyswisseph` | Точные эфемериды (NASA/JPL based) |

### Алгоритм `calculate_natal_chart()`

1. Парсинг `birth_date` (DD.MM.YYYY) → (day, month, year)
2. Парсинг `birth_time` (HH:MM или «не знаю») → (hour, minute); при неизвестном — 12:00
3. Геокодинг `birth_place` через Nominatim → (lat, lng)
4. Определение часового пояса через TimezoneFinder
5. Создание `AstrologicalSubject` с `zodiac_type="Tropic"|"Sidereal"`, `online=False`
6. Извлечение позиций 10 планет из `subject.<planet>`: sign, degree, house, retrograde
7. Извлечение Асцендента из `subject.first_house.sign`
8. Расчёт аспектов через `AspectsFactory.single_chart_aspects(subject.model())`
9. Возврат структурированного dict (см. ниже)

### Структура возвращаемого dict

```python
{
  "sun_sign": "Овен",         # знак Солнца
  "moon_sign": "Рак",          # знак Луны

  "chart_system": "western",   # "western" или "vedic"
```

## Ключевые точки карты

- **Асцендент (AC)** — 1-й дом, «маска» личности, как воспринимают другие. Критично зависит от точного времени.
- **Медиум Цели (MC)** — 10-й дом, карьера, статус, призвание.
- **Десцендент (DC)** — 7-й дом, партнёрство, брак.
- **IC** — 4-й дом, семья, корни.

## Особенности при неизвестном времени рождения

- Луна может находиться в двух разных знаках в течение дня (смена примерно раз в 2.5 дня)
- Асцендент меняется каждые ~2 часа — его нельзя рассчитать
- Дома неизвестны — используется синтетическая карта (noon chart или whole-sign по знаку Солнца)
- Рекомендация боту: явно сообщать пользователю о снижении точности
