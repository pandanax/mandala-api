# Прогнозы и транзиты: как это работает

> Астрологическая математика прогнозов. Статус в коде: частично (LLM без реальных позиций).

## Что такое транзиты

Транзиты — текущие позиции планет в реальном времени и их аспекты к натальным позициям.
Главный инструмент прогнозирования в западной астрологии.

**Пример:** Если в вашей натальной карте Солнце в 5° Овна, а транзитный Юпитер сейчас в 7° Овна
(соединение ±2°) — это позитивный транзит, благоприятный для экспансии, успеха.

## Как планеты движутся (влияние на прогнозы)

| Планета | Скорость движения | Длительность транзита через точку |
|---------|------------------|----------------------------------|
| Луна | 1°/час | ~4 часа |
| Солнце | 1°/день | 3–5 дней |
| Меркурий | ~1.2°/день (c ретро) | 1–4 недели |
| Венера | ~1.2°/день (c ретро) | 1–4 недели |
| Марс | ~0.5°/день (c ретро) | 3–6 недель |
| Юпитер | ~0.083°/день | ~1 месяц |
| Сатурн | ~0.033°/день | ~1.5 месяца |
| Уран | ~0.011°/день | ~6 месяцев |
| Нептун | ~0.007°/день | ~6–12 месяцев |
| Плутон | ~0.004°/день | ~1–2 года |

**Вывод:** Персональный прогноз «на сегодня» определяется прежде всего транзитами Луны, Солнца,
Меркурия и Венеры к натальным точкам. Юпитер и Сатурн — «на месяц/год».

## Орбы для транзитов

Орбы при транзитах обычно уже, чем в натальной карте:
- Внешние медленные планеты (Юп–Плутон): ±2–3°
- Внутренние быстрые (Солнце–Марс): ±1–2°
- Луна: ±1° (иначе слишком много «активных» транзитов)

## Текущее состояние в коде

**Проблема:** Кнопки «📅 Сегодня», «📆 Неделя» и т.д. уже есть и передают LLM промпт
«Дай прогноз на сегодня по моей карте». Но LLM получает только **натальные данные** —

Это значит, что сейчас LLM генерирует прогноз на основе натальной карты и общих знаний о
транзитах, без реальных позиций. Это — **ограничение**, которое нужно исправить.

## Другие методы прогнозирования (западная)

### Солнечные дуги (Solar Arc)
Все планеты продвигаются на ~1° в год (по степени движения Солнца).
Прогрессированная карта для года жизни = натальная + N° сдвига.

### Вторичные прогрессии (Secondary Progressions)
«День за год»: день жизни после рождения = год жизни.
3-й день после рождения → 3-й год жизни.

### Солярный возврат (Solar Return)
Карта на момент, когда Солнце возвращается в точную натальную позицию (день рождения, ±1 день).
Действует 1 год.

## Ведические прогнозы: система Даши

**Главный инструмент Джйотиш.** Даши — планетарные периоды (см. foundations.md).
Определяются позицией Луны в накшатре при рождении.

Комбинация «активная Маха-даша + Антар-даша + транзитный Юпитер/Сатурн» даёт прогноз.
